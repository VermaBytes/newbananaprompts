# My Test Notes

AI Prompts posts may store an optional `testNotes` object in `data/posts.json`
with `whatITried`, `whatFailed`, and `whatFixedIt` string fields.

Record only firsthand observations: the actual prompt/input/settings tried,
the failure observed, and the change that fixed it. Leave unknown fields absent.
Empty or missing notes do not render. Notes are plain text, not HTML.
No existing post has been given invented notes or results.
